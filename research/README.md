# GPU performance research cache (Powder Toy 3D)

The cached copies (raw/, text/) stay local and are git-ignored: the repo (codyhxyz/Powder-Toy-3D) is public, and they are other
people's papers, slides and talks. sources.md and KNOWLEDGE.md (our own notes) are committed.

Each topic folder holds:
- `sources.md`   URL, retrieval date, licence/availability note for each item
- `raw/`         the cached copies (PDF, HTML) as downloaded
- `text/`        plain-text transcripts of each (pdftotext / lit / transcript pages), the files agents read
- `KNOWLEDGE.md` what the sources actually say (quoted, with section/page/timestamp refs), then how it
                 applies to our renderer, and what we have missed
