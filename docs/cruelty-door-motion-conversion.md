# Door motion conversion ABI (version 1)

Conversion-only contract. Existing public payloads are not regenerated by this
change. Runtime pose application, GPU word uploads, streaming, collision, damage
and save-state behavior belong to the runtime integration. Legacy manifests
without `motion` remain valid. No additional GPU bindings or triangle words.

## Source rules

Read as data, never execute scripts. References are recovered `Scripts/Door.gd`
(5–6, 21–40, 55–64), `Elevator_Door.gd` (3–4, 17–37, 44–89), and
`down_door.gd` (3–4, 16–36, 43–78).

- `_ready` selects the **last direct MeshInstance**, using its raw mesh-local
  AABB, including stored surface AABB padding; not its world AABB. The importer
  retains these bounds alongside baked positions.
- Swing rebase q is `(px,0,pz+sz/2)` when sx>sz, otherwise
  `(px+sx/2,0,pz)`. Sliding/vertical rebase is `(px,0,pz)`.
- The literal mixed-space rebase subtracts q from the root **global** origin,
  then `child.transform.translated(q)` adds `childBasis*q` in root space.
  Thus the closed geometry shift is `rootWorldBasis*childBasis*q - q`.
  Conversion bakes this shift once, before the single SAT walk. Runtime progress
  zero is the converted closed pose, not the authored pre-`_ready` pose.
- Swing changes root Euler Y negatively, 2 rad/s, nominal angle -π/2. Root
  yaw-only transforms and arbitrary rigid parent/mesh rotations are supported;
  swing's world axis is parent Y. Translation uses **parent** axes, not mesh axes.
- Horizontal slide opens along negative parent X when sx>sz, negative parent Z
  when sx<sz, and both for a square AABB. Scalar travel is max(sx,sz)+0.1 meters
  (diagonal Euclidean travel is √2 times that); speed is 2 meters/s.
- Vertical opens along negative parent Y, travel sy+0.1 meters, speed 2 meters/s.
- Sliding/vertical `use` starts the 5-second timer at **activation**, not at the
  open endpoint. Vertical `switch_use` does not start a timer.
- Explicit finite positive speed overrides win; absent values use the cited
  script defaults. Invalid overrides do not silently fall back. Raw primitive
  authored properties remain separate from effective/default values.

Deliberate deterministic adaptation: nominal endpoint clamping instead of the
source's strict-threshold one-tick overshoot; no stop/toggle mid-motion quirk.
`doorProgressAtTime` also defines deterministic closing when opening would take
longer than five seconds. Actual state-machine reversal is runtime-owned.

Scaled/sheared/reflected transforms, unresolved parents, separate unsupported
transform components, root pitch/roll, and multiple/excluded moving meshes are
reported as unsupported rather than guessed. Special progression gates remain
closed/unsupported. Recovered Levels 1/2/3/4/6 have no unsupported ordinary transforms.

## JSON and pure math

`interactions.doors[]` retains `sourcePath`, `sourceResource`, `sourceProperties`,
`bounds` (closed surface cell bounds), `cells` (exclusive flat index/id pairs),
`kind`, and `supported`. New conversion adds `motion`, `diagnostics`, and
`appearanceTriangleIndices` (zero-based payload triangle record indices).
Unsupported records have `motion:null` and diagnostics. `interactions.version`
remains 1: the new fields are additive and the packed cell format is unchanged.

Supported `motion` fields:

| Field | Contract |
| --- | --- |
| `version`, `kind` | 1; swing, sliding, or vertical |
| `pivot`, `axis` | world-cell pivot; unit world rotation axis |
| `angleRadians` | swing only: -π/2 |
| `translation`, `distance` | translations only: world-cell vector and scalar travel |
| `speed` | radians/s for swing; scalar cells/s for translations |
| `sourceSpeed`, `speedProperty` | original m/s or rad/s; source property key |
| `durationSeconds` | nominal scalar travel / speed |
| `autoCloseSeconds` | null for swing; 5 for timed use |
| `switchUseAutoCloseSeconds` | null (vertical switch-use has no timer) |
| `sweptBounds` | complete conservative world-cell envelope |
| `selectedMesh` | selected source node path |
| `rawLocalBounds`, `sourceRebase`, `closedSourceOffset` | **source-meter** metadata, not cell coordinates |
| `defaults`, `defaultCitations`, `adaptation`, `units` | explicit provenance and interpretation |

`src/world/import/doorMotion.js` has no Three dependency. `doorPose(motion,f)`
clamps normalized progress to [0,1] and returns 12 numbers: column-major 3×3
basis followed by XYZ translation (Godot Transform layout). It transforms
**converted closed world-cell points** to current pose. `transformDoorPoint`
includes translation; `transformDoorVector` does not. Its inverse is the rigid
transpose basis with inverse translation; consumers must not apply the source
rebase a second time.

`doorSweptBounds` evaluates endpoints and all analytic angular extrema for every
point, so quarter-turn midpoint bulges cannot escape. The converter pads this
surface sweep by 2√3 cells: an owned closed unit voxel lies at most √3 cells from
a SAT hit, and another √3 covers destination-cell rasterization. It is a
conservative envelope, not a solid geometry carve. Sweep bounds extend map
extents when necessary. `doorBrickKeys` shares the inclusive 8-cell brick walk
between physical reservation and appearance directory expansion.
`sweptDoorBounds(motion,closedBounds,fromProgress=0,toProgress=1)` provides a
corner-arc envelope of a closed AABB for per-step safety (opening or closing).
It does not add voxel rasterization padding. The point-list `doorSweptBounds`
helper accepts the same optional progress range.

## Packed storage and appearance

The one physical SAT walk feeds occupancy, exclusive ownership and appearance.
Analysis/rebasing is shared, not re-derived by each consumer. Overlapping static
geometry or another mover disqualifies cell ownership exactly as before.
Originally empty sparse bricks covering the entire sweep receive allocated
**all-zero** 128-word storage. No cells are filled or carved; `stats.cells` is
unchanged by reservation (`stats.reservedBricks` counts extra allocations).

Appearance stays `source-triangle-appearance-u32-v1`, **24 words per triangle**.
Every emitted supported door triangle is entered once into every brick of that
door's complete padded swept envelope. The immutable directory can contain
false positives, rejected by the existing closest-plane/normal/barycentric/id
guards. `appearanceTriangleIndices` identifies exactly which existing records
runtime may transform. It must update p0, UV affine gradients/constants, plane
normal/constant, and barycentric gradients/constants by the same rigid pose;
material-index word 3 stays unchanged. Directory lists, material records, native
UV values, textures/pixels and bindings do not change per pose.

The header's `maxBrickTriangles` includes the expanded directory. Conversion
throws at >=1024; it never truncates entries or changes the shader bound.

## CPU verification

```sh
npm ci --ignore-scripts
node --test tools/door-motion-check.mjs tools/appearance-conversion-check.mjs tools/import-cruelty-map-check.mjs
CRUELTY_SOURCE_ROOT=/path/to/recovered GDRE_BIN=/path/to/gdre node tools/door-motion-source-check.mjs
```

The optional source check converts only original door meshes from Levels 1/2/3/4/6,
checks all owned-cell centers at five poses, every triangle index in every swept
brick, and the actual packed appearance bound. It does not write public assets.
