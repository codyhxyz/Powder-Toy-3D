# POV tool models

The first-person (POV) tool viewmodels are Kenney assets, released under
**Creative Commons Zero (CC0 1.0)**: http://creativecommons.org/publicdomain/zero/1.0/

Created and distributed by Kenney (https://www.kenney.nl). Credit is not required; we give it anyway.

| File | Pack | Used for |
|---|---|---|
| `blaster-kit/blaster-j.glb` | [Blaster Kit 2.1](https://www.kenney.nl/assets/blaster-kit) | Gun |
| `blaster-kit/blaster-q.glb` | [Blaster Kit 2.1](https://www.kenney.nl/assets/blaster-kit) | Physgun |
| `blaster-kit/Textures/colormap.png` | [Blaster Kit 2.1](https://www.kenney.nl/assets/blaster-kit) | the Blaster Kit palette texture |
| `survival-kit/tool-shovel.glb` | [Survival Kit 2.0](https://www.kenney.nl/assets/survival-kit) | Shovel |
| `survival-kit/bucket.glb` | [Survival Kit 2.0](https://www.kenney.nl/assets/survival-kit) | Bucket |
| `survival-kit/tool-axe.glb` | [Survival Kit 2.0](https://www.kenney.nl/assets/survival-kit) | Axe |
| `survival-kit/Textures/colormap.png` | [Survival Kit 2.0](https://www.kenney.nl/assets/survival-kit) | the Survival Kit palette texture |

The files are unmodified copies from the packs' `Models/GLB format/` folders. Each `.glb` loads its pack's
`Textures/colormap.png` by relative path, which is why each pack keeps its own folder.
